# Ultimate Power Simulator

A 3D simulator game project built with Godot.

## Current files

- `Player.gd` — basic 3D player movement using Godot's built-in input actions.
- `Main.tscn` — starter 3D scene with a ground plane, player capsule, camera, and directional light.

## Import into Godot on Android

1. Download the repository as a ZIP from GitHub using **Code → Download ZIP**.
2. Extract the ZIP with your Android file manager.
3. In Godot, import/open the extracted folder as a project.
4. Open `Main.tscn` and run the scene.

## Important notes

- The player script currently uses keyboard-style input actions; on-screen Android touch controls still need to be added.
- If Godot reports that the folder is not a project, the repository needs a `project.godot` file before it can be opened as a complete project.
